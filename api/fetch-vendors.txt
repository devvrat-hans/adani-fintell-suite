# Fetch Vendors API Endpoint

## Endpoint Details
- **URL**: `https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/fetch-vendors`
- **Method**: `GET`
- **Content-Type**: `application/json`

## Description
This endpoint retrieves a list of all vendors from the database with their complete information including contact details, GST information, and current status.

## Query Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| page | number | No | Page number for pagination (default: 1) |
| limit | number | No | Number of vendors per page (default: 10) |
| search | string | No | Search query to filter vendors |
| status | string | No | Filter by vendor status (active/inactive) |
| sortBy | string | No | Field to sort by (vendorCode, vendorName, etc.) |
| sortOrder | string | No | Sort order (asc/desc) |

## Request Example
```javascript
// Fetch all vendors with pagination
const response = await fetch('https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/fetch-vendors?page=1&limit=10', {
    method: 'GET',
    headers: {
        'Content-Type': 'application/json'
    }
});

const data = await response.json();
```

## Vendor Object Schema
| Field | Type | Description |
|-------|------|-------------|
| vendorCode | string | Unique vendor identification code |
| vendorName | string | Full legal name of the vendor |
| gstNumber | string | GST registration number (15 characters) |
| contactPerson | string | Primary contact person name |
| email | string | Vendor's email address |
| phone | string | Contact phone number with country code |
| address | string | Registered business address |
| status | string | Vendor status (active/inactive) |
| createdAt | string | ISO 8601 timestamp of vendor creation |
| updatedAt | string | ISO 8601 timestamp of last update |

## Usage Notes
1. **Pagination**: Always use pagination for large datasets to improve performance
2. **Search**: The search parameter searches across vendorCode, vendorName, gstNumber, and contactPerson fields
3. **Filtering**: Use status parameter to filter active or inactive vendors
4. **Sorting**: Combine sortBy and sortOrder parameters for custom sorting
5. **Rate Limiting**: API calls are limited to 100 requests per minute per user

## Frontend Integration Example
```javascript
// api-service.js integration
async function fetchVendors(params = {}) {
    const queryParams = new URLSearchParams({
        page: params.page || 1,
        limit: params.limit || 10,
        ...(params.search && { search: params.search }),
        ...(params.status && { status: params.status }),
        ...(params.sortBy && { sortBy: params.sortBy }),
        ...(params.sortOrder && { sortOrder: params.sortOrder })
    });

    const response = await fetch(
        `https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/fetch-vendors?${queryParams}`,
        {
            method: 'GET',
            headers: {
                'Content-Type': 'application/json'
            }
        }
    );

    if (!response.ok) {
        throw new Error('Failed to fetch vendors');
    }

    return await response.json();
}
```

## Status Codes
- **200**: Success - Vendors fetched successfully
- **400**: Bad Request - Invalid parameters
- **401**: Unauthorized - Authentication required
- **403**: Forbidden - Access denied
- **404**: Not Found - No vendors found
- **500**: Internal Server Error - Server-side error
