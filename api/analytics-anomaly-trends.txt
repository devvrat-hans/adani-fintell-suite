## Analytics - Anomaly Trends API

**Endpoint:** `https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/analytics/anomaly-trends`

**Method:** GET

**Description:** Returns anomaly detection trends over time by type for line chart visualization.

**Query Parameters:**
- `timeRange` (optional): Time range filter - "7", "30", "90", "365", or "all" (default: "30")
- `startDate` (optional): Start date for custom range (format: YYYY-MM-DD)
- `endDate` (optional): End date for custom range (format: YYYY-MM-DD)
- `granularity` (optional): Data granularity - "daily", "weekly", "monthly" (default: "weekly")

**Response Structure:**

```json
{
  "success": true,
  "data": {
    "labels": ["Week 1", "Week 2", "Week 3", "Week 4"],
    "duplicate": [8, 6, 9, 5],
    "price": [5, 7, 4, 6],
    "gst": [3, 2, 4, 3],
    "risk": [6, 5, 8, 4],
    "total": [22, 20, 25, 18],
    "summary": {
      "totalAnomalies": 85,
      "duplicateCount": 28,
      "priceCount": 22,
      "gstCount": 12,
      "riskCount": 23,
      "trend": "decreasing",
      "percentageChange": -8.5
    },
    "period": {
      "start": "2024-10-01",
      "end": "2024-10-31"
    }
  },
  "timestamp": "2024-11-04T10:30:00Z"
}
```

**Error Response:**

```json
{
  "success": false,
  "error": "Error message describing what went wrong",
  "timestamp": "2024-11-04T10:30:00Z"
}
```

**Usage Example:**

```javascript
// Fetch anomaly trends data
async function fetchAnomalyTrends(timeRange = '30') {
    try {
        const response = await fetch(
            `https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/analytics/anomaly-trends?timeRange=${timeRange}`
        );
        
        const result = await response.json();
        
        if (result.success) {
            const { labels, duplicate, price, gst, risk } = result.data;
            
            // Update line chart with data
            createAnomalyTrendsChart({
                labels,
                datasets: [
                    { label: 'Duplicate', data: duplicate, color: '#BD3861' },
                    { label: 'Price', data: price, color: '#FFC107' },
                    { label: 'GST', data: gst, color: '#0B74B0' },
                    { label: 'Risk', data: risk, color: '#DC3545' }
                ]
            });
            
            // Update summary metrics
            const { summary } = result.data;
            document.getElementById('totalAnomalies').textContent = summary.totalAnomalies;
        } else {
            console.error('Error:', result.error);
        }
    } catch (error) {
        console.error('Failed to fetch anomaly trends:', error);
    }
}
```

**n8n Workflow Notes:**
- Query anomaly detection database for detected anomalies within specified date range
- Group by time period (based on granularity) and anomaly type
- Anomaly types:
  - **duplicate**: Duplicate invoice detection
  - **price**: Price anomaly detection (market price comparison)
  - **gst**: GST validation errors
  - **risk**: High-risk score invoices
- Count anomalies in each category for each period
- Calculate trend direction and percentage change
- Return structured data for multi-line chart visualization
