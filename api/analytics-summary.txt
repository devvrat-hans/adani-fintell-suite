## Analytics - Summary Metrics API

**Endpoint:** `https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/analytics/summary`

**Method:** GET

**Description:** Returns high-level summary metrics for the analytics dashboard header cards.

**Query Parameters:**
- `timeRange` (optional): Time range filter - "7", "30", "90", "365", or "all" (default: "30")
- `startDate` (optional): Start date for custom range (format: YYYY-MM-DD)
- `endDate` (optional): End date for custom range (format: YYYY-MM-DD)

**Response Structure:**

```json
{
  "success": true,
  "data": {
    "totalInvoices": 1247,
    "invoiceChange": 12.5,
    "totalSpend": 45678900,
    "spendChange": 8.3,
    "complianceRate": 94.5,
    "complianceChange": 2.1,
    "anomalyCount": 43,
    "anomalyChange": -5.2,
    "period": {
      "start": "2024-10-01",
      "end": "2024-10-31"
    },
    "previousPeriod": {
      "start": "2024-09-01",
      "end": "2024-09-30"
    }
  },
  "timestamp": "2024-11-04T10:30:00Z"
}
```

**Field Descriptions:**
- **totalInvoices**: Total number of invoices processed in the period
- **invoiceChange**: Percentage change compared to previous period (positive = increase)
- **totalSpend**: Total invoice amount in INR
- **spendChange**: Percentage change in spend compared to previous period
- **complianceRate**: Percentage of invoices that are fully compliant (GST, validation, etc.)
- **complianceChange**: Percentage point change in compliance rate
- **anomalyCount**: Total number of anomalies detected
- **anomalyChange**: Percentage change in anomaly count (negative = improvement)

**Error Response:**

```json
{
  "success": false,
  "error": "Error message describing what went wrong",
  "timestamp": "2024-11-04T10:30:00Z"
}
```

**Usage Example:**

```javascript
// Fetch summary metrics
async function fetchSummaryMetrics(timeRange = '30') {
    try {
        const response = await fetch(
            `https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/analytics/summary?timeRange=${timeRange}`
        );
        
        const result = await response.json();
        
        if (result.success) {
            const { data } = result;
            
            // Update Total Invoices card
            document.getElementById('totalInvoices').textContent = data.totalInvoices.toLocaleString();
            document.getElementById('invoiceChange').textContent = `${data.invoiceChange >= 0 ? '+' : ''}${data.invoiceChange}%`;
            document.getElementById('invoiceChange').className = `metric-change ${data.invoiceChange >= 0 ? 'positive' : 'negative'}`;
            
            // Update Total Spend card
            document.getElementById('totalSpend').textContent = formatCurrency(data.totalSpend);
            document.getElementById('spendChange').textContent = `${data.spendChange >= 0 ? '+' : ''}${data.spendChange}%`;
            
            // Update Compliance Rate card
            document.getElementById('complianceRate').textContent = `${data.complianceRate}%`;
            document.getElementById('complianceChange').textContent = `${data.complianceChange >= 0 ? '+' : ''}${data.complianceChange}%`;
            
            // Update Anomaly Count card
            document.getElementById('anomalyCount').textContent = data.anomalyCount;
            document.getElementById('anomalyChange').textContent = `${data.anomalyChange}%`;
            // Note: For anomaly count, negative change is positive (fewer anomalies)
            document.getElementById('anomalyChange').className = `metric-change ${data.anomalyChange >= 0 ? 'negative' : 'positive'}`;
        } else {
            console.error('Error:', result.error);
        }
    } catch (error) {
        console.error('Failed to fetch summary metrics:', error);
    }
}
```

**n8n Workflow Notes:**
- Calculate current period metrics:
  - Count total invoices
  - Sum total invoice amounts
  - Calculate compliance rate (compliant invoices / total invoices)
  - Count total anomalies detected
- Calculate previous period metrics for comparison
- Compute percentage changes for each metric
- Return structured data with current values and change indicators
