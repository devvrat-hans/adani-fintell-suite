GET https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/anomalies

Description:
Fetches all detected anomalies from processed invoices including duplicate invoices, price anomalies, GST compliance issues, and risk scores.

Request:
GET request with optional query parameters for filtering:
- type: Filter by anomaly type (duplicate, price_anomaly, gst_compliance, high_risk)
- severity: Filter by severity (high, medium, low)
- date_from: Filter anomalies from this date (ISO format)
- date_to: Filter anomalies to this date (ISO format)
- limit: Number of results to return (default: 50)
- offset: Pagination offset (default: 0)

Anomaly Types:
1. duplicate - Duplicate invoice detection
2. price_anomaly - Price deviations from market rates
3. gst_compliance - GST validation failures
4. high_risk - High-risk invoices based on multiple factors

Severity Levels:
1. high - Immediate attention required (risk score 80-100)
2. medium - Review recommended (risk score 50-79)
3. low - Minor issues (risk score 0-49)

Status Types:
1. flagged - Anomaly detected and flagged for review
2. under_review - Being reviewed by compliance team
3. resolved - Anomaly resolved or false positive confirmed
