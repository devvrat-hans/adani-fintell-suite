POST https://n8n-n8n.qoezvx.easypanel.host/webhook/f/database/add-feedback

Description:
Submit feedback for a processed invoice. This endpoint allows users to report processing errors, OCR issues, validation problems, or any other issues encountered during invoice processing.

Request Headers:
Content-Type: application/json

Request Body:
{
  "invoice_id": "IN000000000000001",
  "invoice_number": "CONS-2025-789",
  "vendor_name": "Business Advisory Services LLP",
  "feedback_type": "ocr_error",
  "severity": "critical",
  "title": "Invoice number extracted incorrectly",
  "description": "The OCR system extracted the invoice number as 'C0NS-2025-789' instead of 'CONS-2025-789'. The zero was misread as the letter O.",
  "expected_result": "CONS-2025-789",
  "actual_result": "C0NS-2025-789",
  "affected_fields": "invoice_number",
  "suggested_fix": "Improve OCR training for alphanumeric characters",
  "submitted_at": "2025-11-05T10:30:00.000Z",
  "submitted_by": {
    "name": "Rajesh Kumar",
    "email": "rajesh.kumar@adani.com"
  }
}

Field Descriptions:

invoice_id (string, required):
  The unique identifier of the processed invoice

invoice_number (string, required):
  The invoice number from the processed invoice

vendor_name (string, required):
  The name of the vendor from the processed invoice

feedback_type (string, required):
  Type of issue encountered. Must be one of:
    - "ocr_error": OCR extraction errors
    - "data_mismatch": Data does not match expected values
    - "gst_validation_error": GST validation issues
    - "duplicate_detection_error": Duplicate detection problems
    - "amount_calculation_error": Calculation errors
    - "hsn_sac_error": HSN/SAC code errors
    - "vendor_details_error": Vendor information errors
    - "line_items_error": Line item extraction errors
    - "other": Other issues

severity (string, required):
  Severity level of the issue. Must be one of:
    - "critical": Processing completely failed or incorrect
    - "major": Significant errors requiring attention
    - "minor": Small errors or formatting issues

title (string, required):
  Brief summary of the issue (max 200 characters)

description (string, required):
  Detailed description of the issue

expected_result (string, optional):
  What was the expected result

actual_result (string, optional):
  What was the actual result

affected_fields (string, optional):
  Comma-separated list of fields affected by the issue

suggested_fix (string, optional):
  User's suggestion on how to fix the issue

submitted_at (string, required):
  ISO 8601 timestamp of when the feedback was submitted

submitted_by (object, required):
  Information about the user who submitted the feedback
    - name (string): User's full name
    - email (string): User's email address

Response (Error - 400 Bad Request):
{
  "success": false,
  "error": "Validation error",
  "message": "Invalid feedback_type. Must be one of: ocr_error, data_mismatch, gst_validation_error, duplicate_detection_error, amount_calculation_error, hsn_sac_error, vendor_details_error, line_items_error, other"
}

Response (Error - 404 Not Found):
{
  "success": false,
  "error": "Invoice not found",
  "message": "Invoice with ID 'IN000000000000001' not found in database"
}

Response (Error - 500 Internal Server Error):
{
  "success": false,
  "error": "Internal server error",
  "message": "Failed to submit feedback. Please try again later."
}

Notes:
- All timestamps should be in ISO 8601 format (UTC)
- The feedback_id is auto-generated by the backend
- Status is automatically set to "open" when created
- The endpoint validates that the invoice_id exists in the database before accepting feedback
- Duplicate feedback detection can be implemented based on invoice_id + feedback_type + submitted_by combination
