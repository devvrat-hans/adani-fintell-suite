🧪 FinGuard API Endpoint Tester

1. Detect Duplicate Invoice

POST

https://n8n-n8n.j8euv3.easypanel.host/webhook/f/finguard/detect-duplicate

Request Body (JSON):
Response:
Note: This endpoint checks if the invoice already exists in the system to prevent duplicate entries. Response includes confidence score, matched invoice IDs, duplicate type (exact_match/fuzzy_match), and reason for duplicate detection.

2. Validate GST

POST

https://n8n-n8n.j8euv3.easypanel.host/webhook/f/finguard/validate-gst

Request Body (JSON):
Response:
Note: This endpoint validates GST numbers against government databases and checks tax calculations for accuracy.

3. Validate GST Rate

POST

https://n8n-n8n.j8euv3.easypanel.host/webhook/f/finguard/validate-gst-rate

Request Body (JSON):
Response:
Note: This endpoint validates GST rates applied on line items against correct rates for their HSN/SAC codes. Returns all_rates_valid (boolean) and list of invalid_items if any discrepancies are found.
4. Add Vendor
POST /webhook/f/vendor-master/add-vendor
Request Body:
Response:
Note: This endpoint adds a new vendor to the vendor master database. The vendor_code will be auto-generated by the backend. Returns success status and the generated vendor code along with vendor ID.
5. Add Purchase Order
POST /webhook/f/purchase-orders/add-po
Request Body:
Response:
Note: This endpoint creates a new purchase order with complete details including line items, financial summary, and approval workflow. The PO number is automatically generated by the backend. Vendor must be selected from the existing vendor database using vendor_code. Returns success status and the generated PO number and PO ID.
6. Fetch Purchase Orders
GET /webhook/f/database/fetch-purchase-orders
Request Body:
Response:
Note: This endpoint retrieves all purchase orders from the database. Returns an array of PO objects with basic information.
7. Get Purchase Order Details
POST /webhook/f/purchase-orders/get-po-details
Request Body:
Response:
Note: This endpoint retrieves complete details of a specific purchase order including all line items, financial summary, and metadata.
