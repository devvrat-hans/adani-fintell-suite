## Analytics - Payment Patterns API

**Endpoint:** `https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/analytics/payment-patterns`

**Method:** GET

**Description:** Returns invoice payment pattern distribution by payment days buckets for bar chart visualization.

**Query Parameters:**
- `timeRange` (optional): Time range filter - "7", "30", "90", "365", or "all" (default: "30")
- `startDate` (optional): Start date for custom range (format: YYYY-MM-DD)
- `endDate` (optional): End date for custom range (format: YYYY-MM-DD)

**Response Structure:**

```json
{
  "success": true,
  "data": {
    "labels": ["0-15 Days", "16-30 Days", "31-45 Days", "46-60 Days", "60+ Days"],
    "values": [234, 456, 312, 178, 67],
    "percentages": [18.8, 36.6, 25.0, 14.3, 5.3],
    "totalInvoices": 1247,
    "avgPaymentDays": 28.5,
    "medianPaymentDays": 26,
    "onTimePayments": 690,
    "onTimePercentage": 55.4,
    "period": {
      "start": "2024-10-01",
      "end": "2024-10-31"
    }
  },
  "timestamp": "2024-11-04T10:30:00Z"
}
```

**Error Response:**

```json
{
  "success": false,
  "error": "Error message describing what went wrong",
  "timestamp": "2024-11-04T10:30:00Z"
}
```

**Usage Example:**

```javascript
// Fetch payment patterns data
async function fetchPaymentPatterns(timeRange = '30') {
    try {
        const response = await fetch(
            `https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/analytics/payment-patterns?timeRange=${timeRange}`
        );
        
        const result = await response.json();
        
        if (result.success) {
            const { labels, values, avgPaymentDays, onTimePercentage } = result.data;
            
            // Update bar chart with data
            createPaymentPatternsChart({
                labels,
                datasets: [
                    { label: 'Invoices', data: values, color: '#0B74B0' }
                ]
            });
            
            // Update additional metrics
            document.getElementById('avgPaymentDays').textContent = `${avgPaymentDays} days`;
            document.getElementById('onTimePayments').textContent = `${onTimePercentage}%`;
        } else {
            console.error('Error:', result.error);
        }
    } catch (error) {
        console.error('Failed to fetch payment patterns:', error);
    }
}
```

**n8n Workflow Notes:**
- Query invoice database for paid invoices within specified date range
- Calculate payment days for each invoice (payment_date - invoice_date)
- Bucket invoices into payment day ranges:
  - 0-15 days
  - 16-30 days
  - 31-45 days
  - 46-60 days
  - 60+ days
- Count invoices in each bucket
- Calculate statistics: average, median, on-time payment counts
- On-time is typically considered ≤30 days (configurable)
- Return structured data for bar chart and metrics display
