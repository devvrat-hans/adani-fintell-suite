Usage Notes:
1. This endpoint returns all processed invoices from the database
2. Invoices are returned in reverse chronological order (most recent first)
3. The response can be cached in localStorage for performance
4. The API should be called when the page loads and when the refresh button is clicked
5. Filter and search functionality should be implemented on the frontend using the fetched data
6. The overall_status field can be used to filter invoices by their processing result

Frontend Implementation:
```javascript
// Fetch processed invoices
async function fetchProcessedInvoices() {
    try {
        const response = await fetch('https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/fetch-processed-invoices', {
            method: 'GET'
        });
        
        const result = await response.json();
        
        if (result[0].success) {
            const invoices = result[0].data;
            
            // Store in localStorage
            localStorage.setItem('processed_invoices', JSON.stringify(invoices));
            
            // Display invoices
            displayInvoices(invoices);
        } else {
            console.error('Failed to fetch invoices:', result[0].error);
        }
    } catch (error) {
        console.error('Error fetching invoices:', error);
    }
}

// Get invoices from localStorage
function getStoredInvoices() {
    const stored = localStorage.getItem('processed_invoices');
    return stored ? JSON.parse(stored) : [];
}

// Filter invoices by status
function filterByStatus(status) {
    const invoices = getStoredInvoices();
    return invoices.filter(inv => inv.overall_status === status);
}
```

Filtering Examples:
- Show all completed invoices: Filter by overall_status === 'completed'
- Show failed invoices: Filter by overall_status === 'failed'
- Show invoices with warnings: Filter by overall_status === 'completed_with_warnings'
- Search by invoice number: Filter by invoice_data.invoice_number
- Search by vendor: Filter by invoice_data.vendor_name
- Filter by date range: Compare processed_at timestamps
