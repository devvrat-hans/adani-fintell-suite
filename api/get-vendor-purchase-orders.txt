API Name: Get Vendor Purchase Orders
API Type: GET
Endpoint: /webhook/f/vendor-master/get-vendor-purchase-orders

Description:
Retrieves all purchase orders associated with a specific vendor. Used in the vendor purchase orders page to display PO history and track vendor transactions.

Request Parameters:
{
  "vendorCode": "VEN-00123",     // Required - Unique vendor identifier
  "status": "All",                // Optional - Filter by status: All, Pending, Approved, Completed, Cancelled
  "startDate": "2025-01-01",      // Optional - Filter POs from this date (YYYY-MM-DD)
  "endDate": "2025-12-31",        // Optional - Filter POs until this date (YYYY-MM-DD)
  "page": 1,                      // Optional - Page number for pagination (default: 1)
  "limit": 20,                    // Optional - Number of records per page (default: 20)
  "sortBy": "poDate",             // Optional - Sort field: poDate, poNumber, amount
  "sortOrder": "desc"             // Optional - Sort order: asc, desc (default: desc)
}

Request Headers:
{
  "Content-Type": "application/json",
  "Authorization": "Bearer <token>"
}

Usage Notes:
- Vendor code is mandatory
- Supports filtering by status, date range
- Supports pagination for large datasets
- Returns summary statistics for all POs of the vendor
- POs are sorted by date (most recent first) by default
- All amounts are in the specified currency
- Dates are in YYYY-MM-DD format
