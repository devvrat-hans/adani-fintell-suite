## Analytics - Invoice Trends API

**Endpoint:** `https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/analytics/invoice-trends`

**Method:** GET

**Description:** Returns invoice processing trends over time, showing successful and failed invoice processing counts.

**Query Parameters:**
- `timeRange` (optional): Time range filter - "7", "30", "90", "365", or "all" (default: "30")
- `startDate` (optional): Start date for custom range (format: YYYY-MM-DD)
- `endDate` (optional): End date for custom range (format: YYYY-MM-DD)
- `granularity` (optional): Data granularity - "daily", "weekly", "monthly" (default: "weekly")

**Response Structure:**

```json
{
  "success": true,
  "data": {
    "labels": ["Week 1", "Week 2", "Week 3", "Week 4"],
    "processed": [280, 310, 295, 362],
    "failed": [12, 8, 15, 8],
    "total": [292, 318, 310, 370],
    "successRate": [95.9, 97.5, 95.2, 97.8],
    "period": {
      "start": "2024-10-01",
      "end": "2024-10-31"
    }
  },
  "timestamp": "2024-11-04T10:30:00Z"
}
```

**Error Response:**

```json
{
  "success": false,
  "error": "Error message describing what went wrong",
  "timestamp": "2024-11-04T10:30:00Z"
}
```

**Usage Example:**

```javascript
// Fetch invoice trends data
async function fetchInvoiceTrends(timeRange = '30') {
    try {
        const response = await fetch(
            `https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/analytics/invoice-trends?timeRange=${timeRange}`
        );
        
        const result = await response.json();
        
        if (result.success) {
            const { labels, processed, failed } = result.data;
            
            // Update chart with data
            createInvoiceTrendsChart({
                labels,
                datasets: [
                    { label: 'Processed', data: processed, color: '#0B74B0' },
                    { label: 'Failed', data: failed, color: '#DC3545' }
                ]
            });
        } else {
            console.error('Error:', result.error);
        }
    } catch (error) {
        console.error('Failed to fetch invoice trends:', error);
    }
}
```

**n8n Workflow Notes:**
- Query database for invoice processing records within specified date range
- Group by time period based on granularity parameter
- Calculate success/failure counts for each period
- Return structured data for chart visualization
