Field Descriptions:

Basic Information:
- po_date: Date when PO is created (YYYY-MM-DD format) [REQUIRED]
- po_status: Current status of PO (draft/pending_approval/approved/sent_to_vendor/acknowledged/in_progress/received/completed/cancelled) [REQUIRED]

Vendor Reference:
- vendor_code: MongoDB _id of the vendor from vendor database [REQUIRED]
- vendor_name: Name of the vendor/supplier [REQUIRED]
- vendor_gst_number: Vendor's GST identification number

Delivery Details:
- ship_to_address: Delivery address details
  - address_line1: Primary address line [REQUIRED]
  - city: City name [REQUIRED]
  - state: State name [REQUIRED]
  - pin_code: PIN/ZIP code [REQUIRED]
- requested_delivery_date: Expected delivery date (YYYY-MM-DD format) [REQUIRED]
- shipping_method: Method of shipping (road_transport/rail_transport/air_freight/sea_freight/courier)
- special_instructions: Additional delivery instructions

Line Items:
- line_number: Sequential item number [REQUIRED]
- item_description: Description of the item [REQUIRED]
- hsn_code: HSN/SAC code for the item [REQUIRED]
- quantity: Quantity ordered [REQUIRED]
- unit_of_measurement: Unit of measurement (KG/BAG/PCS/LITRE/METRE/TON/SET/BOX) [REQUIRED]
- unit_price: Price per unit [REQUIRED]
- line_total: Total before tax (quantity × unit_price) [AUTO-CALCULATED]
- tax_rate: Tax rate percentage [REQUIRED]
- tax_amount: Tax amount (line_total × tax_rate / 100) [AUTO-CALCULATED]
- line_total_with_tax: Total including tax [AUTO-CALCULATED]

Financial Summary:
- subtotal: Sum of all line_total values [AUTO-CALCULATED]
- total_tax_amount: Sum of all tax_amount values [AUTO-CALCULATED]
- other_charges: Additional charges object
  - freight_charges: Freight/transportation charges
  - packaging_charges: Packaging charges
  - handling_charges: Handling charges
- total_other_charges: Sum of all other charges [AUTO-CALCULATED]
- grand_total: subtotal + total_tax_amount + total_other_charges [AUTO-CALCULATED]
- currency: Currency code (default: INR)

Payment Terms:
- payment_method: Method of payment (bank_transfer/cheque/cash/credit_card/online_payment)
- payment_due_days: Number of days for payment
- advance_payment_percentage: Percentage of advance payment required
- payment_schedule: Payment schedule description (net_30/net_45/net_60/advance/cod)

Approval Workflow:
- created_by: Name of person creating the PO [REQUIRED]
- approver_name: Name of approver
- approval_status: Current approval status (pending/approved/rejected)
- approval_notes: Notes from approver

Budget Allocation:
- department: Department name
- cost_center: Cost center code
- project_code: Project code for budget tracking
- budget_year: Budget year

Contract Reference:
- contract_number: Reference contract number
- contract_date: Contract date (YYYY-MM-DD format)
- contract_validity: Contract validity end date (YYYY-MM-DD format)

Metadata:
- priority: Priority level (low/medium/high/urgent)
- business_unit: Business unit name
- tags: Array of tags for categorization
- internal_notes: Internal notes/comments

Notes:
- po_number is auto-generated by the backend (MongoDB _id)
- All monetary values should be in decimal format
- Dates should be in YYYY-MM-DD format
- Required fields are marked with [REQUIRED]
- AUTO-CALCULATED fields are computed on frontend before submission
  - quantity: Quantity ordered
  - unit: Unit of measurement (KG, BAG, PC, etc.)
  - unit_price: Price per unit
  - discount: Discount amount on this line item
  - taxable_amount: Amount before tax (after discount)
  - gst_rate: GST percentage applicable
  - cgst: Central GST amount
  - sgst: State GST amount
  - igst: Integrated GST amount (for inter-state)
  - total_amount: Total amount for this line item (including tax)
- subtotal: Sum of all line items before discount
- total_discount: Total discount applied
- total_taxable_amount: Total amount before tax
- total_cgst: Total Central GST
- total_sgst: Total State GST
- total_igst: Total Integrated GST
- total_gst: Total GST amount
- total_amount: Final total amount
- created_by: Name of user who created the PO

Notes:
- All amount fields are in INR (Indian Rupees)
- GST calculations should be accurate
- For inter-state transactions, use IGST instead of CGST+SGST
- Date format must be YYYY-MM-DD
- Line items can be dynamically added/removed
