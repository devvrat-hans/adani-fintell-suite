## Analytics - Spend by Category API

**Endpoint:** `https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/analytics/spend-by-category`

**Method:** GET

**Description:** Returns total spend breakdown by invoice category for visualization in doughnut/pie chart.

**Query Parameters:**
- `timeRange` (optional): Time range filter - "7", "30", "90", "365", or "all" (default: "30")
- `startDate` (optional): Start date for custom range (format: YYYY-MM-DD)
- `endDate` (optional): End date for custom range (format: YYYY-MM-DD)
- `limit` (optional): Maximum number of categories to return (default: 6, others grouped as "Others")

**Response Structure:**

```json
{
  "success": true,
  "data": {
    "labels": [
      "Raw Materials",
      "Equipment",
      "Services",
      "Utilities",
      "Transportation",
      "Others"
    ],
    "values": [15234500, 8765400, 7654300, 5432100, 4321000, 4271600],
    "percentages": [33.5, 19.3, 16.8, 11.9, 9.5, 9.0],
    "totalSpend": 45678900,
    "period": {
      "start": "2024-10-01",
      "end": "2024-10-31"
    }
  },
  "timestamp": "2024-11-04T10:30:00Z"
}
```

**Error Response:**

```json
{
  "success": false,
  "error": "Error message describing what went wrong",
  "timestamp": "2024-11-04T10:30:00Z"
}
```

**Usage Example:**

```javascript
// Fetch spend by category data
async function fetchSpendByCategory(timeRange = '30') {
    try {
        const response = await fetch(
            `https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/analytics/spend-by-category?timeRange=${timeRange}&limit=6`
        );
        
        const result = await response.json();
        
        if (result.success) {
            const { labels, values } = result.data;
            
            // Update doughnut chart with data
            createSpendAnalysisChart({
                labels,
                data: values,
                colors: ['#0B74B0', '#75479C', '#BD3861', '#28A745', '#FFC107', '#17A2B8']
            });
        } else {
            console.error('Error:', result.error);
        }
    } catch (error) {
        console.error('Failed to fetch spend by category:', error);
    }
}
```

**n8n Workflow Notes:**
- Query invoice database for approved invoices within specified date range
- Group by category field and sum invoice amounts
- Sort by amount descending
- Take top N categories (based on limit parameter)
- Group remaining categories as "Others"
- Calculate percentages for each category
- Return structured data for doughnut chart visualization
