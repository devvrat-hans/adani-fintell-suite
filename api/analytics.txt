## Analytics API Endpoint

**Endpoint:** `https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/analytics`

**Method:** GET

**Query Parameters:**
- `timeRange` (optional): Time range filter - "7", "30", "90", "365", or "all" (default: "30")
- `startDate` (optional): Start date for custom range (format: YYYY-MM-DD)
- `endDate` (optional): End date for custom range (format: YYYY-MM-DD)

**Error Response:**

```json
{
  "success": false,
  "error": "Error message describing what went wrong",
  "timestamp": "2024-11-04T10:30:00Z"
}
```

**Usage Example:**

```javascript
// Fetch analytics data
const response = await fetch('https://n8n-n8n.qoezvx.easypanel.host/webhook/f/finguard/analytics?timeRange=30');
const data = await response.json();

if (data.success) {
    // Process analytics data
    console.log('Total Invoices:', data.data.summary.totalInvoices);
    console.log('Compliance Rate:', data.data.summary.complianceRate);
} else {
    console.error('Error:', data.error);
}
```

**Notes:**
- All monetary values are in INR (Indian Rupees)
- Percentages are returned as decimal numbers (e.g., 94.5 means 94.5%)
- Change percentages can be positive or negative
- Time ranges: 7 = last 7 days, 30 = last 30 days, 90 = last 90 days, 365 = last year, all = all time
- For custom date ranges, use both startDate and endDate parameters
