Response Body (Error):
{
    "success": false,
    "error": "Error message description"
}

Field Descriptions:
- po_id: Unique purchase order ID (required for editing)
- status: Current status of PO ("Pending", "Approved", "Rejected", "Completed", "Cancelled")
- updated_by: Name of user who updated the PO
- All other fields same as add-purchase-order endpoint

Notes:
- PO ID is required to identify which order to update
- Status can be changed during editing
- Cannot edit PO if status is "Completed" or "Cancelled"
- Date format must be YYYY-MM-DD
