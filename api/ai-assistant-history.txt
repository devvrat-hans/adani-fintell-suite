=======================================================================
Endpoint: AI Assistant - Get Conversation History
=======================================================================

Purpose: Retrieve chat history for current user

URL: /api/ai-assistant/history
Method: GET
Authentication: Required (Session Token)

-------------------------------------------------------------------
Query Parameters
-------------------------------------------------------------------
- limit: number (optional, default: 20) - Number of conversations to return
- offset: number (optional, default: 0) - Pagination offset
- session_id: string (optional) - Get specific conversation history

Example Request:
GET /api/ai-assistant/history?limit=10&offset=0

-------------------------------------------------------------------
Response (Success - 200 OK)
-------------------------------------------------------------------
{
    "success": true,
    "data": {
        "conversations": [
            {
                "session_id": string - Unique session identifier
                "title": string - Auto-generated conversation title
                "started_at": string - ISO 8601 timestamp
                "last_updated": string - ISO 8601 timestamp
                "message_count": number - Number of messages in conversation
                "preview": string - Preview of last message
            }
        ],
        "total": number - Total conversation count
        "pagination": {
            "limit": number,
            "offset": number,
            "has_more": boolean
        }
    }
}

-------------------------------------------------------------------
n8n Workflow Integration
-------------------------------------------------------------------
1. Workflow: ai-assistant-get-history
2. Trigger: Webhook GET /api/ai-assistant/history
3. Steps:
   a. Validate authentication
   b. Query conversation database
   c. Format and paginate results
   d. Return conversation list

-------------------------------------------------------------------
Notes
-------------------------------------------------------------------
- Conversations are ordered by last_updated (most recent first)
- Title is auto-generated from first message or manually set
- Preview shows last 100 characters of most recent message
- Deleted conversations are not returned
