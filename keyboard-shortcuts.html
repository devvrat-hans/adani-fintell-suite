Keyboard Shortcuts

Quick reference guide for navigating and using Adani-Fintell-Suite efficiently

Global Navigation

Ctrl + K
Open command palette / Quick search
Alt + 1
Go to Home / Dashboard
Alt + 2
Go to FinGuard
Alt + 3
Go to SheetSense
Alt + 4
Go to Analytics Dashboard
Alt + 5
Go to Settings
Esc
Close modal / dialog / cancel action

File Operations

Ctrl + U
Open file upload dialog
Ctrl + S
Save current form / download report
Ctrl + P
Print current page / Export to PDF
Ctrl + D
Download selected file / report

FinGuard - Invoice Processing

Ctrl + Enter
Approve current invoice
Ctrl + R
Reject current invoice
Ctrl + V
Validate GST number
N
Next invoice (when viewing list)
P
Previous invoice (when viewing list)

SheetSense - Balance Sheet

Ctrl + G
Generate report
Ctrl + F
Find / Filter GL accounts
Ctrl + E
Export trial balance to Excel

Analytics Dashboard

Ctrl + Shift + R
Refresh dashboard data
Ctrl + T
Toggle time range selector
Ctrl + H
Toggle chart visualization mode

Form & Field Navigation

Tab
Move to next field
Shift + Tab
Move to previous field
Enter
Submit form / Confirm action
Space
Toggle checkbox / Select button

Accessibility

Alt + 0
Skip to main content
Ctrl + +
Zoom in (increase text size)
Ctrl + -
Zoom out (decrease text size)
Ctrl + 0
Reset zoom to 100%

Pro Tips

  • On Mac, use Cmd instead of Ctrl
  • Press ? on any page to see page-specific shortcuts
  • Most shortcuts work even when focus is not on a specific field
  • You can customize keyboard shortcuts in Settings
